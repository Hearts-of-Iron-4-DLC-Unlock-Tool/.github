# Automatic Hearts of Iron IV DLC Unlocker – CreamAPI

A Windows utility for managing DLC unlock in **Hearts of Iron IV** using CreamAPI. Designed to unlock all DLCs in all versions of the game, both in MP and single player, modded and unmodded versions of the game..

## Requirements

Before getting started, make sure you have:

- A legitimate Steam installation of Hearts of Iron IV.
- The latest compatible release of CreamAPI.
- An active internet connection where required.
- .NET 7 Runtime, if required by the application.

---

## Installation & Setup

1. Download the latest compatible release.
2. Extract the `.zip` archive to a folder of your choice.
3. Read the included documentation.
4. Follow the setup instructions provided by the application.
5. Launch Hearts of Iron IV and check your game configuration.

**Note:** Only use DLC and game content that you are licensed to access. Compatibility may vary depending on your game version and installed content.

---

## Troubleshooting

| Problem | Suggested Solution |
|---|---|
| DLC content is not appearing | Check your Steam installation and verify your DLC ownership and game files. |
| Game crashes on startup | Verify the integrity of your game files through Steam and check for incompatible modifications. |
| Missing DLL errors | Make sure all required runtime dependencies are installed. |
| Changes are not taking effect | Restart Steam and Hearts of Iron IV after changing the configuration. |
